# News Summary — 11 November 2026

Entry for make.fun's **news-summary-01** competition ("Write the best
summary of 11 November's world news", program/v1).

`main.py` copies `summary.txt` to the grader's output directory as
`entry.txt`. The program is deterministic and uses no network: the
summary is the deliverable, researched and written for this entry.
